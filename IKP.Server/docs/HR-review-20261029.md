# HR review — 2026-10-29

## Проверка переработанного архива

Проверены HR domain entities, EF configurations, `AppDbContext`, seed `AppHRSeed`, миграция `20261029173737_HrFoundation`, DI и текущий `EmployeesController`.

## Найдено и исправлено

1. `EmployeesController` расширен для истории занятости, контактов, образования и квалификаций.
2. `EmployeeService.DeleteAsync` переведен на soft delete; `Get/Update` не работают с удаленными сотрудниками; restore работает с удаленной записью.
3. В `EmployeeConfiguration` убрано дублирование конфигурации `FirstName`/`IsDeleted`.
4. Индекс `CompetencyMatrixItems` больше не уникален по `(IsDeleted, SectionId)`. Старый вариант разрешал только один item на section.
5. Seed HR справочников переведен на фиксированные ID, соответствующие уже созданной `HrFoundation` migration. Это предотвращает случайную смену seed ID при следующем scaffolding migration.
6. В типы вопросов аттестации добавлен `Открытый ответ`, поскольку ТЗ содержит открытые/самостоятельные вопросы.

Для Employee добавлены endpoints дочерних HR-данных.

## Что осталось намеренно не делать автоматически

- scope authorization HR (`HRAll`, `Department`, `DirectReports`, `Self`) пока не подменяется простой permission `employees.read/manage`;
- email/phone verification workflow пока не привязан к EmployeeContact;
- Excel importer матрицы пока не добавляется в migration/seed: текущая модель и API готовы принять матрицу, но импорт большого XLSX лучше сделать отдельным сервисом после согласования правил преобразования Topic/Competency/Skill и колонок Position/Grade;
- фактические 140 сотрудников, подразделения и должности из оргструктуры не зашиваются в migration без отдельного подтвержденного seed-файла.

## Требуется новая migration

После этих изменений необходимо создать новую EF migration. Она должна содержать:

- изменение индекса `CompetencyMatrixItems`;
- добавление `Открытый ответ` в `AttestationQuestionType`.

Команда:

```powershell
dotnet ef migrations add HrControllersAndSeedFix --project IKP.Infrastructure --startup-project IKP.Api
dotnet ef database update --project IKP.Infrastructure --startup-project IKP.Api
```

Текущий архив не собирался в окружении агента: .NET SDK отсутствует.
